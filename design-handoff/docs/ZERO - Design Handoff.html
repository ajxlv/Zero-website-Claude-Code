ZERO website: design handoff

Everything a front-end developer needs to build the approved green design. Generated 5 Nov 2026 from the project "Zero Design System progress" (non-"-old-" Site pages only: Archive, old versions, other directions and the comparison page are excluded).

Read this first: what this handoff is and is not.
  • Source of truth. The approved design is the 9 final pages + shared Header and Footer. Token, type and spacing values below were read from the design source, not invented. Where a value is Proposed (focus, active, disabled, error states; reduced-motion fallbacks; mobile adjustments) the design is silent and a badge says so.
  • The HTML pages are reference builds, not production code. They are standalone and work offline, and every interaction works, but they run on the design tool's own runtime (React 18 + a template layer, inline styles). Rebuild them in your framework from this document; use the pages to compare pixels and behaviour.
  • Page list differs from the brief. Net Zero Events, ESG Assessment and Carbon Calculator are sections of Services and Free Tools. The blog template is the page named Blog Article. Three final pages were not in the brief: Platform, Pricing and Contact.
  • No grid system and no responsive spec existed. The design is fluid (flex-wrap, clamp()). Tablet and mobile views are renders of that fluid layout plus a small safety layer; they were not designed. See Layout and Open items.

3. Layout

Container and grid

  • Content max width 1280px centred, horizontal padding 32px (inner 1216px at ≥1344). Narrow column 1080px (quotes), article ~760px.
  • There is no 12-column grid. Layouts are flex rows with flex-wrap:wrap and basis values (e.g. flex:1.2 1 460px), or CSS grid with repeat(auto-fit,minmax(240–300px,1fr)). Gutters: 16 / 24 / 32 / 40 / 48 / 56px by section. Implement as a 12-col, 24px gutter grid only if you want one; match visual widths, not tracks.
  • Section vertical padding: 96–120px desktop, 64–72px for heroes; side gutter 32px (proposed 16–20px under 640px).
  • Header 80px sticky. Anchor offset: add scroll-margin-top:96px (proposed).

Free Tools · ESG assessment (6 questions → score → result)

  1. Measurement: Do you measure your greenhouse gas emissions today? (Not yet / Scope 1 and 2 only / Scope 1, 2 and 3)
  2. Data: Where does your sustainability data live? (Scattered across teams and email / Spreadsheets with an owner / A central system with an audit trail)
  3. Targets: Have you set emission reduction targets? (No targets yet / Internal targets / Science-based (SBTi) targets)
  4. Reporting: Which frameworks do you report to? (None / One, on request from customers / BRSR, GRI, CSRD or CDP every year)
  5. Supply chain: Do you collect sustainability data from suppliers? (No / From a few key suppliers / From most suppliers, with primary data)
  6. Governance: Who owns ESG in your organisation? (No clear owner / A part-time owner / A board-level owner with a team)
Each option = 0, 1 or 2 points (top to bottom). Clicking an option records it and advances immediately.
